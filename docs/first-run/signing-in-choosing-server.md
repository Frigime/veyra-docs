# Signing In & Choosing Your Server

The last step: sign in with your own Discord account, then tell Veyra which server to run on.

## Sign in with Discord

Click **Continue with Discord**. You'll be sent to Discord's real sign-in page — Veyra never sees or stores your Discord password, only a secure, expiring session token after you approve.

## Choose or invite your server

Veyra shows every server where your account has **Manage Server** or **Administrator** permission, split into two groups:

- **Veyra is already here** — servers the bot has already been invited to; click **Manage** to select one.
- **Available servers** — servers you can administer but haven't invited the bot to yet; click **Add Bot** to send Discord's normal bot-invite flow, then come back and select it.

::: tip Nothing is selected automatically
Veyra never picks a server for you. If your server doesn't show up, make sure your account actually has Manage Server or Administrator on it, then click **Refresh status**.
:::

## You're done

Once you select a server, Veyra finishes setting up and takes you straight to the [Dashboard](/dashboard/tour).
