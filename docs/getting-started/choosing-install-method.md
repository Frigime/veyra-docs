# Choosing an Install Method

Veyra runs the same way everywhere — the only difference is how you get it started. Pick whichever matches where you're running it.

| You have… | Use | 
|---|---|
| A Windows PC you'll keep running | [Windows (One-Click Scripts)](/installation/windows) — double-click two files, no terminal required. |
| A Linux or macOS machine, or a VPS you're comfortable with a terminal on | [Linux, macOS & VPS](/installation/linux-macos-vps) — three copy-paste commands. |
| Docker already installed, and you want easy updates/isolation | [Docker](/installation/docker) — two commands, everything containerized. |
| A rented game/app hosting panel (Pterodactyl, Pelican, etc.) | [Pterodactyl / Pelican](/installation/pterodactyl) — panel-specific steps. |

::: tip Not sure?
If you're not sure, and you're on Windows, use the **Windows (One-Click Scripts)** path — it's the least technical option and doesn't require you to type any commands.
:::

Whichever you choose, installation ends the same way: your terminal or panel console prints a **First-Run Setup Security Code**, and you open Veyra's dashboard in a browser to continue. That's covered once, for everyone, in [First-Run Setup](/first-run/unlocking-setup) — but first, you'll need a Discord application. See [Discord Setup](/discord-setup/creating-application) after installing.
