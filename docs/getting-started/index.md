# Welcome to Veyra

Veyra is a self-hosted Discord bot studio: instead of inviting a bot you don't control and hoping it does what you want, you run Veyra yourself and configure it through a real web dashboard.

Everything in Veyra follows the same loop:

::: tip Configure → Preview → Deploy
You change a setting in the dashboard, see exactly what it will look like on Discord, and then explicitly send it live. Nothing you type in the dashboard reaches your real Discord server until you tell it to.
:::

This documentation is written for the person actually running the bot — not a developer extending Veyra's code. If you've never self-hosted anything before, that's fine: every command you need to copy is shown exactly, and every screen you'll see is described before you get there.

## How this documentation is organized

The sections in the sidebar follow the order you'll actually go through them:

1. **Getting Started** *(you are here)* — what you need before you begin.
2. **Installation** — get Veyra running on your machine, server, or panel.
3. **Discord Setup** — create the Discord application Veyra will use.
4. **First-Run Setup** — the in-dashboard wizard that connects everything.
5. **Dashboard** — how the control center works, including the single most important concept in the product: [Draft, Deploy & Publish](/dashboard/draft-deploy-publish).
6. **Moderation, Community, Support, Engagement, Voice & Music, Automation, Configuration** — one page per module, grouped exactly like Veyra's own sidebar.
7. **Maintenance** — backups and updates.
8. **Troubleshooting / FAQ** — what to do when something doesn't look right.
