# Automations

**Automations** lets you build simple "when this happens, do that" workflows visually — no code — using a trigger, optional conditions, and one or more actions.

## Setting it up

1. Enable **Automations** from [Modules](/dashboard/modules-page).
2. Open **Automations**, either start from a **Quick-Start template** (for example "Auto-Star Images" — reacts with ⭐ to messages with attachments) or build one from scratch.
3. Choose a **trigger** (e.g. a message is sent, a member joins, a voice state changes).
4. Optionally add **conditions** that must also be true (e.g. the message has attachments).
5. Add one or more **actions** (add a reaction, send a reply, assign a role, send a log, and more).
6. Set a priority and cooldown if you have multiple rules that could overlap.
7. Click **Save & Activate Workflow** — automations go live immediately once activated, without a separate deploy step.

## Managing workflows

The Automations page lists every active rule, how many times it's fired, and lets you disable or edit it at any time.
