# Social Feeds

**Social Feeds** automatically posts to a Discord channel whenever a followed external source publishes something new — RSS feeds, and other supported providers.

## Setting it up

1. Enable **Social Feeds** from [Modules](/dashboard/modules-page).
2. Open **Social Feeds**, add a feed: give it a name, paste the source (for an RSS feed, its URL), and pick the channel to post updates to.
3. Customize the message template and whether updates post as a rich embed.
4. Optionally set a role to ping when a new item is posted.
5. Save the draft, then [deploy](/dashboard/draft-deploy-publish).

Veyra checks each feed on its own schedule and posts anything new automatically — no further action needed once deployed.
