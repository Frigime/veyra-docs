# Goodbye

**Goodbye** posts a message when a member leaves your server — the counterpart to [Welcome](/community/welcome).

## Setting it up

1. Enable **Goodbye** from [Modules](/dashboard/modules-page).
2. Open **Goodbye**, choose the channel to post in.
3. Write your message, using variables like `{displayName}` and `{server}`.
4. Save the draft, then [deploy](/dashboard/draft-deploy-publish).
