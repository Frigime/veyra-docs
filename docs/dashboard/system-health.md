# System Health

**System** shows the real-time health of your Veyra installation: whether the API, dashboard, database, and Discord connection are all responding normally, plus process uptime and version information.

This is the first place to check if something in Veyra seems broken — a red or unhealthy status here tells you which part of the system is having trouble, before you go looking through individual modules. It's also useful information to include if you ever need to [get help](/troubleshooting/getting-help).

Open **Configuration → System** in the sidebar to view it.
