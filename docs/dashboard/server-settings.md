# Server Settings

**Server Settings** controls how Veyra's dashboard identifies and presents this particular Discord server — separate from your bot's identity, which lives in [Bot Settings](/dashboard/bot-settings).

Here you can adjust things like the studio's accent color and other per-server dashboard preferences. Changes here follow the normal [Draft, Deploy & Publish](/dashboard/draft-deploy-publish) flow like everything else.

Open **Configuration → Server Settings** in the sidebar.
