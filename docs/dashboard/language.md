# Language

Veyra supports five languages, and the dashboard and bot can each be set independently: **English, French, Spanish, German, and Italian**.

## Two separate settings

- **Dashboard language** — what *you* see when administering Veyra.
- **Bot language** — what Veyra's own messages on Discord (welcome messages, verification prompts, AutoMod warnings, etc.) are written in for your members.

These don't have to match — you can run the dashboard in English while your bot speaks French to your server, for example.

Open **Configuration → Language** in the sidebar to change either one.
