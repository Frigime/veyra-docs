# Dashboard Tour

Once setup is complete, this is where you'll spend all your time: Veyra's dashboard, also called the Studio.

![Veyra's dashboard control center, with the sidebar's feature groups expanded](/screenshots/dashboard/overview.png)

## The sidebar

The left sidebar is organized into the same groups as this documentation:

- **Overview** — the home Control Center, [Analytics](/dashboard/analytics), and [Activity](/dashboard/activity).
- **Moderation** — Moderation, AutoMod, Anti-Raid, Anti-Nuke, Logs.
- **Community** — Welcome, Goodbye, Verification, Roles, Levels, Economy.
- **Support** — Tickets.
- **Engagement** — Giveaways, Polls.
- **Voice & Music** — Music, Temporary Voice.
- **Automation** — Automations, Custom Commands, Social Feeds.
- **Configuration** — Modules, Embed Builder, Server Settings, Bot Settings, Themes, Language, System.

## The header

At the top of every page you'll find:

- Your server's connection status (whether Veyra's Discord connection is live).
- The **Brouillon / Deployed revision** indicator — your unsaved draft number versus what's actually live. This is explained fully in [Draft, Deploy & Publish](/dashboard/draft-deploy-publish), the single most important concept on this page.
- The **Deploy changes** button.

## Getting oriented

If this is your first time here, read [Draft, Deploy & Publish](/dashboard/draft-deploy-publish) next — it explains how every module page on this site actually takes effect on your real Discord server.
