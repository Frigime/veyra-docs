# Themes

Veyra ships four signature visual themes for the dashboard itself — this only changes how the dashboard *looks* to whoever's administering it; it has no effect on Discord.

![The Themes page's theme picker](/screenshots/dashboard/themes.png)

## Available themes

- **Veyra Night** *(default)* — deep midnight glass with ambient blue glow.
- **Liquid Light** — bright, high-contrast frosted daylight glass.
- **Obsidian** — monolithic dark charcoal with a sharper, less glowing look.
- **Golden Hour** — warm sunset tones with gilded accents.

## Switching themes

Open **Configuration → Themes**, click the theme you want. Unlike most settings, this applies instantly — no deploy step needed, since it only affects the dashboard's appearance, not your Discord server.

Each server you manage can have its own theme.
