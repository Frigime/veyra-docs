# Activity

**Activity** is Veyra's audit log — a chronological record of configuration changes and system events on your server. Like Analytics, it's a built-in dashboard page, not a module you enable.

Every deploy, publish, and module toggle you make shows up here with a timestamp — useful if you're trying to remember what changed, or when.

Open **Overview → Activity** in the sidebar to view it. There's nothing to configure.
