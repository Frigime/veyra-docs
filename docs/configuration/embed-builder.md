# Embed Builder

**Embed Builder** is a reusable tool for composing rich Discord embeds — visually, without knowing Discord's embed format — for reuse anywhere in Veyra that accepts a rich message (Welcome, Goodbye, Automations actions, and more).

## What it's for

Embed Builder itself doesn't post anything on its own — it's a shared editor other modules' message fields can use when you choose **Embed** as the message format instead of plain text. Enable it from [Modules](/dashboard/modules-page) to make the richer composition tools available across the dashboard.

::: tip Not a standalone feature
If you're looking for where a *specific* message is configured — say, your Welcome message or a Ticket panel's message — go to that module's own page. Embed Builder is the tool those pages use, not a destination on its own.
:::
