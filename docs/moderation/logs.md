# Logs

**Logs** posts a record of Discord server events — messages deleted or edited, members joining/leaving/being updated, channels and roles changing, voice activity, and server-level changes — to a channel of your choice.

## Setting it up

1. Enable **Logs** from [Modules](/dashboard/modules-page).
2. Open **Logs** and set a **default log channel**.
3. Each event category (Messages, Members, Channels, Roles, Voice, Server) can be turned on or off independently, and optionally routed to its own separate channel instead of the default.
4. Save the draft, then [deploy](/dashboard/draft-deploy-publish).

## See also

Logs is a general Discord event log. For staff actions specifically (warnings, bans, timeouts), see [Moderation](/moderation/moderation)'s case history instead.
