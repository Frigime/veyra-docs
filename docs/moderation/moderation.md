# Moderation

The **Moderation** module gives your staff warnings, bans, and timeouts with a real case history — the record of every action taken, who took it, and why.

## What you'll need first

A text channel for the mod-log, if you want a running record of actions posted to Discord.

## Setting it up

1. Enable **Moderation** from [Modules](/dashboard/modules-page).
2. Open **Moderation** in the sidebar and pick a **mod-log channel**.
3. Optionally enable **notify by DM** so members are messaged directly when an action is taken against them, with a customizable message.
4. Save the draft, then [deploy](/dashboard/draft-deploy-publish).

## Case history

Every warning, ban, and timeout issued through Veyra (from this module or triggered by AutoMod) is recorded as a case, visible in the **Dossiers/Cases** tab — searchable by member, with the reason and moderator attached.

## See also

[AutoMod](/moderation/automod) for automatic message filtering, and [Logs](/moderation/logs) for a broader Discord event log beyond moderation actions.
