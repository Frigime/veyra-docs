# Giveaways

**Giveaways** runs prize drawings in your server, with eligibility rules, a live entrant count, and an automatic winner draw when time runs out.

## Setting it up

1. Enable **Giveaways** from [Modules](/dashboard/modules-page).
2. Open **Giveaways**, create a new giveaway: name, prize, channel, number of winners, and end time.
3. Optionally restrict entry — required roles, forbidden roles, minimum account age, minimum server membership age — or boost certain roles' odds with bonus weight.
4. Save the draft, then [deploy](/dashboard/draft-deploy-publish).
5. Click **Publish** to post the giveaway and open entries.

## While it's running

Veyra tracks entrants automatically. When the end time is reached, Veyra draws winners on its own — you don't need to be online. You can also **End now**, **Cancel**, or **Reroll** a giveaway's winners from the dashboard at any time.
