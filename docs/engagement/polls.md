# Polls

**Polls** posts interactive, real-time voting polls to a channel.

## Setting it up

1. Enable **Polls** from [Modules](/dashboard/modules-page).
2. Open **Polls**, click **Create Poll** — write your question, add options, and choose a duration.
3. Decide whether members can select multiple options or only one.
4. Publish it directly from the creation dialog — polls don't need a separate deploy step; they're a one-off action, not standing configuration.

## Results

Votes update in real time on the Discord message itself. Once a poll ends, Veyra shows the final tally.
